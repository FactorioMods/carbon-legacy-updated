# Carbon: Legacy Updated

Retains the legacy Adamo Carbon processing chain: natural gas, syngas, methane, gasifier recipes and their startup choices.

The port updates prototypes and recipe handling for Factorio 2.1.24 or later and adopts original Carbon save state. It works with the base game and retains the optional Adamo Physics integration.

Original project: [fixadamo-carbon](https://mods.factorio.com/mod/fixadamo-carbon) — Adamo and the continuation credited to lool23232; the original Mod Portal entry is maintained by LostIntelligence.
